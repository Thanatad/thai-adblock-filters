# 🛡️ Thai Adblock Filters

A collection of custom ad-blocking rules designed to strip out intrusive banners, betting ads, and promotional overlays across popular Thai websites (Streaming & Manga/Doujin portals) 🇹🇭.

---

## 🚀 Key Features
* **Video Ad Bypass:** Strips out VAST video ad overlays and scripts on streaming sites.
* **Floating Ad Removal:** Eliminates sticky side banners, corner pop-ups, and fake close buttons.
* **Layout Cleanup:** Collapses parent containers so empty ad spaces don't leave blank gaps.
* **Lightweight:** Uses precise element-hiding CSS selectors that won't slow down page loading.
